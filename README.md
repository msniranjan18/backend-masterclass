## 🗂️ How to Use This Book

- Each **chapter** has its own folder with a `README.md` overview page.
- Each **topic** is a dedicated `.md` file with a consistent structure.
- Use the **Table of Contents** above to jump to any section.
- Add your notes under the designated `<!-- NOTES -->` markers in each file.

---

## 📋 Topic File Template

Every topic file follows this structure:

```
# Topic Name

## Overview
## Core Concepts
## Key Commands / Code Snippets
## Common Interview Questions
## Gotchas & Best Practices
## Resources
## My Notes
```
